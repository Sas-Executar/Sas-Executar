# Design SOT

A identidade visual não deve ser redefinida neste pacote.

## Autoridade

Usar o EXECUTAR Visual SOT e o `packages/design-system` do repositório como fonte de verdade quando estiverem integrados.

## Handoff visual

Para cada superfície registrar somente desvios/contexto específico; tokens, símbolos, tipografia, responsividade, overflow, componentes e estados permanecem governados pelo SOT.
