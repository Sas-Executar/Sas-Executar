# Customer Journey

## Macro jornada

```text
Entrar → Capturar → Estruturar → Comprometer → Executar → Controlar → Replanejar → Encerrar
```

## Etapas

| Etapa | Pergunta do usuário | Resultado esperado | Rota dominante |
|---|---|---|---|
| Entrar | Onde estou? | contexto de trabalho | PENDENTE |
| Capturar | O que preciso realizar? | entrada registrada | PENDENTE |
| Estruturar | O que isso exige? | plano compreensível | PENDENTE |
| Comprometer | O plano é viável? | compromisso operacional | PENDENTE |
| Executar | O que faço agora? | próxima ação executável | PENDENTE |
| Controlar | Estou no rumo certo? | estado e desvio visíveis | PENDENTE |
| Replanejar | O que mudou? | novo caminho válido | PENDENTE |
| Encerrar | O que foi entregue? | validação e histórico | PENDENTE |
