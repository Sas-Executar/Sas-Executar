# Acceptance Criteria

## Critérios transversais

- comportamento funcional verificável;
- estados loading/empty/error definidos quando aplicável;
- responsividade e overflow conforme Visual SOT;
- acessibilidade conforme componente/superfície;
- autorização e isolamento quando houver dados multi-tenant;
- testes relevantes verdes;
- documentação atualizada.
